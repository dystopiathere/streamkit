# @streamkit/admin

## Назначение
Административная панель платформы на `admin.<домен>`: пользователи и их
доступы, виджеты и ссылки OBS, комнаты, площадки, платежи, журнал действий и
статистика платформы с графиками. Только для сотрудников с ролью `support`
или `admin` и включённым двухфакторным входом.

## Технологии
React 19, Vite 8, TanStack Query, Zustand (сессия), react-router,
react-i18next, Tailwind 4, recharts (только на обзоре). Интерфейс — из
`@streamkit/app-kit`, данные — схемы `@streamkit/contracts`.

## Структура

| Каталог | Что внутри |
|---|---|
| `src/lib` | Клиент API (свой путь обновления сессии), хранилище сессии, запросы и действия, форматирование |
| `src/components` | Каркас с меню, общие части страниц, ссылки OBS виджета |
| `src/pages` | Обзор, пользователи и карточка, виджеты, комнаты, площадки, платежи, журнал |

## Ключевые решения

**Отдельное приложение, а не раздел дашборда.** Код и маршруты админки не
попадают в бандл, который открывает любой стример, а перед статикой стоит
пароль Caddy (`infra/yandex-cloud/app/Caddyfile`).

**Своя сессия.** Вход — `/api/admin/auth/login` с паролем и кодом TOTP;
refresh-cookie `sk_admin_refresh` живёт на своём пути, блокировка обновления
между вкладками — своя (`streamkit:admin-auth-refresh`). Токен админки не
открывает дашборд, и наоборот.

**Права решает сервер.** Кнопки действий, недоступных роли, не показываются,
но это удобство, а не защита: ручка без права отвечает 403. Сессии и второй
фактор поддержка гасит только стримерам — у аккаунтов сотрудников эти кнопки
видит один админ.

**Действие — через `useAdminAction`.** Он показывает текст ошибки сервера и
сбрасывает весь кэш `['admin']`: отзыв ссылки меняет и карточку, и списки, и
журнал.

**Необратимое подтверждается вводом** (`ConfirmDialog` с `confirmText`):
обезличивание — почтой аккаунта, удаление комнаты — её названием.
Блокировка, бесплатные дни, снятие подарочных дней и обнуление истории донатов
требуют причину — она уходит в журнал.

## Правила

- **Подарочные дни снимаются только подаренные** (`Subscription.giftedDays`):
  оплаченный доступ сотрудник не забирает. Кнопки нет, когда подарка нет.
- **Тариф в карточке — два значения:** действующий и выбранный на следующий
  период. Второй показывается, только когда он другой: «сменится на
  «Мультистрим»» рядом с «Про» объясняет, почему у человека ещё есть комнаты, а
  спишется меньше. Подарок создаёт подписку «Про» — дарится доступ целиком, а не
  урезанный тариф.
  Диалог предупреждает, что срок сдвинется назад: оплата, оформленная поверх
  подарка, съезжает вместе с ним.
- **Обнуление истории донатов — то же действие, что кнопка стримера**
  (`EventsService.resetHistory`): вместе с событиями обнуляются цель и топ
  донатеров в открытых сценах OBS. Делается по просьбе владельца аккаунта, и
  причина с автором остаются в журнале.
- **Данных третьих лиц здесь нет и не будет:** имён и сообщений донатеров,
  ников зрителей, имён гостей (соглашение, раздел 13). События — только числа.
  Функция, которой они понадобятся, — сначала новая редакция соглашения.
- Umami в админке не подключается: сотрудники не посетители сайта.
- Графики — только через `@streamkit/app-kit/chart` и только на лениво
  загружаемых страницах. Главный вход пакета recharts не тянет — и не должен.
- Одна величина на график, у каждого — текстовая сводка. Цвета: количество —
  `#9167ea`, деньги — `#c98500`; пара проверена валидатором skill `dataviz` на
  тёмной карточке.
- Остальные правила вёрстки и доступности — как в `apps/web/CLAUDE.md`:
  `t()` для текста, `usePageTitle` (здесь `useAdminTitle`), `aria-label` с
  именем объекта у кнопок в строках таблиц, статус словом, не только цветом.

## Проверка

```bash
pnpm --filter @streamkit/admin typecheck
pnpm --filter @streamkit/admin test
pnpm --filter @streamkit/e2e exec playwright test tests/admin.spec.ts
```

Локальный вход: `pnpm db:seed` печатает почту, пароль и секрет TOTP сотрудника
`admin@streamkit.local`.
