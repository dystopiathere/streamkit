# 0006. Отдельный интерфейс провайдера для аналитики площадок

Дата: 2026-09-12. Статус: принято.

## Контекст
К моменту начала работы над аналитикой в проекте был ровно один интерфейс
внешней интеграции — `DonationConnector`. Задача формулировалась как «аналитика
поверх готовой абстракции провайдеров», но абстракция оказалась не той:

- `DonationConnector.connect()` возвращает функцию остановки. Это подписка:
  открыл долгоживущее соединение, получаешь события, закрыл.
- `provider` в нём — жёсткий union `'donationalerts' | 'donatepay'`.
- OAuth-контура не было вовсе. Интерфейс `OAuthProviderConfig` был объявлен, но
  ни одна строка кода не выпускала ссылку авторизации, не меняла код на токен и
  не записывала `IntegrationCredential`. Токены появлялись в базе только руками.

Аналитика — это опрос: спроси метрики, получи снимок, закрой соединение.

## Решение
Заведён соседний интерфейс `PlatformProvider` (`buildAuthorizeUrl`,
`exchangeCode`, `refreshTokens`, `fetchIdentity`, `fetchStats`,
`statsQuotaCost`). Общая часть — OAuth и хранение токенов — вынесена в
`PlatformTokenService` и `OAuthStateService`, которыми пользуются оба вида
интеграций.

Расширять `DonationConnector` до обеих форм отвергнуто: пришлось бы сделать
половину методов необязательными, и интерфейс перестал бы что-либо
гарантировать. Реализация `connect()`, внутри которой крутится `setInterval`,
тоже отвергнута — это подделка подписки под опрос ради единообразия названий.

## Последствия
Две абстракции вместо одной, зато каждая описывает ровно то, что происходит.
Новая площадка метрик = класс плюс строка в `PlatformRegistry`; новый источник
донатов = класс плюс строка в `ConnectorManager`.

Побочная выгода: `ConnectorManager` переведён на общий сервис токенов и теперь
замечает истёкший доступ вместо того, чтобы отдать коннектору мёртвый токен и
молча потерять источник донатов.

Цена — разработчику нужно понимать, какой из двух интерфейсов реализовывать.
Ответ простой: площадка присылает события сама — `DonationConnector`, у неё надо
спрашивать — `PlatformProvider`.
