# @streamkit/contracts

## Назначение
Единственный источник правды для данных, пересекающих границу между приложениями:
схемы событий, конфигов виджетов, DTO аутентификации и сообщений реального времени.
Одна и та же Zod-схема валидирует запрос в `apps/api`, строит форму настроек в
`apps/web` и управляет рендером в `apps/overlay`.

## Технологии
- **Zod 4** — схемы и вывод типов (`z.infer`)
- **tsup** — сборка в ESM + CJS + `.d.ts`: `apps/api` на CommonJS, Vite-приложения на ESM
- **Vitest** — юнит-тесты чистых функций

## Состав
| Файл | Что описывает |
|---|---|
| `common.ts` | Деньги, валюты, цвета, https-URL, курсорная пагинация |
| `events.ts` | `AlertEvent`, провайдеры, ключ дедупликации, payload вебхука |
| `chat.ts` | Сообщение чата, значки, разбор диапазонов эмоутов |
| `rooms.ts` | Комнаты, приглашения, доступ LiveKit, идентичности участников, раскладка плиток |
| `widgets.ts` | Конфиги шести типов виджетов, их состояния, шаблоны текста |
| `auth.ts` | Регистрация, логин, согласия 152-ФЗ, сессии |
| `billing.ts` | Тариф: периоды, цены, подписка, платежи |
| `admin.ts` | Админка: роли, вход сотрудника, списки, карточка, статистика — без данных третьих лиц |
| `realtime.ts` | Имена socket-событий, имена комнат, схемы сообщений |
| `stream.ts` | Окно эфира: сводка, канал чата, время стрима и сумма зрителей |
| `messages.ts` | Языки дашборда и английский для русских сообщений API и схем (`MESSAGES_EN`) |

## Правила
- **Только чистый код.** Никаких зависимостей от Nest, React, Prisma, `process.env`,
  сети и файловой системы. Пакет импортируется и бэкендом, и браузером.
- **Деньги — целые минорные единицы** (`amountMinor` + `currency`). `number` с
  плавающей точкой для сумм запрещён везде, включая промежуточные вычисления.
- **Схема раньше типа.** Пишем `z.object(...)`, тип выводим через `z.infer`. Ручной
  `interface`, дублирующий схему, — источник расхождений.
- **Результат `renderTemplate` — текст, не HTML.** Шаблоны пишет пользователь, а
  overlay открыт по публичной ссылке. Вставка только через `textContent`/JSX-текст;
  `dangerouslySetInnerHTML` в рендерерах виджетов запрещён.
- **Внешние ссылки только https** (`httpsUrlSchema`): браузер-сорс OBS блокирует
  смешанный контент, а http-ссылка на чужой хост — это ещё и утечка факта показа.
- **Текст проверки в схеме — сразу со строкой в `MESSAGES_EN`**: его показывает
  и английская форма. Полноту проверяет `messages-en.test.ts` в `apps/api`: у
  пакета нет доступа к файловой системе, а тест читает исходники.
- Поле, живущее внутри одного приложения, сюда не выносим.
- Ломающее изменение схемы виджета = новая версия конфига и миграция существующих
  записей, а не молчаливое изменение формы (см. `configVersion` в Prisma-схеме).
- **Новый тип виджета добавляется в `WIDGET_CONFIG_SCHEMAS`.** Запись объявлена
  как `Record<WidgetType, ...>`, поэтому пропущенный тип ломает компиляцию, а не
  всплывает в рантайме пустым экраном в эфире.
- **Внутреннее состояние сервера сюда не выносится.** В контрактах лежит
  посчитанный снимок (`WidgetState`), который уходит в оверлей; то, что сервер
  хранит для его вычисления, — его собственное дело.
