# @streamkit/ui

## Назначение
Компоненты, которые обязаны выглядеть одинаково в дашборде и в оверлее:
рендерер виджета и логика очереди показа оповещений.

Элементы интерфейса дашборда и админки (кнопки, поля, таблицы, диалоги) сюда НЕ
выносятся: оверлею они не нужны, а пакет обязан обходиться без Tailwind и
роутера. Они живут в `packages/app-kit`.

## Технологии
React 19 (в peer-зависимостях), tsup для сборки в ESM + CJS + типы, Vitest +
Testing Library.

## Состав

| Файл | Что делает |
|---|---|
| `AlertCard.tsx` | Рендерер оповещения: стили целиком выводятся из сценария его типа |
| `alert-animations.tsx` | Keyframes строкой и компонент, который их вставляет |
| `useAlertQueue.ts` | Очередь показа: строго по одному, с паузой между; длительность — из сценария события |
| `GoalBar.tsx` | Полоса цели: прогресс плюс собранная и целевая суммы |
| `TimerDisplay.tsx` | Табло таймера: локальный отсчёт от момента окончания |
| `TopDonorsList.tsx` | Таблица топа донатеров |
| `ChatBox.tsx` | Лента мультичата: значок площадки, ники, значки, эмоуты, фильтр площадок, гашение по сроку |
| `PlatformIcon.tsx` | Значок площадки инлайновым SVG — общий для кадра и окна эфира |
| `ParticipantLayout.tsx` | Раскладка гостей комнаты; от LiveKit не зависит, медиа приходит готовым узлом |
| `text-style.ts` | Оформление текста из конфига в инлайновые стили |
| `slots.tsx` | Продвинутое оформление в кадре: позиции элементов в процентах, фоновый слой, кадр виджета |
| `fonts/` | Шрифты своими файлами (woff2, латиница и кириллица) и `fonts.css`; отдельный вход пакета |

## Правила

- **Только инлайновые стили.** Пакет подключают и приложение с Tailwind, и
  минимальный оверлей без пайплайна стилей вообще. Внешний CSS сделал бы
  подключение разным в двух местах. Исключение одно и вынужденное — `fonts.css`:
  `@font-face` инлайновым стилем не задаётся. Он отдельным входом
  (`@streamkit/ui/fonts.css`), и подключают его оба приложения.
- **Шрифты — своими файлами, не с чужого CDN.** Шрифт, которого нет на машине с
  OBS, молча подменяется системным, и в кадр уходит не то, что настроил
  стример; вдобавок CSP разрешает шрифты только со своего домена. Список имён —
  `FONT_FAMILIES` в контрактах, файлы — в `fonts/`: новое семейство добавляется
  в оба места, иначе выбор в дашборде будет, а шрифта в кадре нет.
- **Позиция элемента — проценты кадра, а не пиксели** (`slots.tsx`). Размер
  браузер-сорса задаёт стример в OBS, и пиксельные координаты разъехались бы у
  каждого по-своему. Пустая позиция (`null`) означает обычный поток: так выглядит
  виджет без продвинутого оформления и любой конфиг, сохранённый до его
  появления.
- **Фон виджета — слой с `z-index: -1` внутри кадра с `isolation: isolate`**
  (`WidgetFrame`). Слой позиционирован абсолютно, а содержимое стоит в потоке,
  и позиционированный элемент рисуется поверх непозиционированных соседей: цвет
  фона закрывал весь текст виджета. `isolation` не даёт слою провалиться под
  подложку предпросмотра или сцену OBS.
- **Тариф в рендерерах не проверяется.** Конфиг приходит уже приведённым к нему
  (`applyPlanToConfig` на сервере и в предпросмотре): решение «что показать»
  принимается один раз, а не в каждом компоненте.
- **Никакого `dangerouslySetInnerHTML`.** Шаблоны пишет пользователь, а оверлей
  открыт по публичной ссылке — это прямой XSS-вектор.
- **Подстановка идёт по частям шаблона, а не по готовой строке.** Иначе донатер
  с ником вроде «задонатил» ломает разметку, а ник, совпавший с куском шаблона,
  подсвечивается не там.
- **Очередь не ограничена по длине.** Потерять донат на стриме хуже, чем
  показать его с задержкой; отсечение всплесков — задача фильтров на бэкенде.
- **Часы не читаются во время рендера.** `Date.now()` в теле компонента делает
  рендер нечистым: один и тот же пропс даёт разный результат, а React вправе
  перерисовать компонент когда угодно. Текущее время живёт в состоянии и
  двигается только из таймеров.
- **Отложенный вызов ровно один за раз, и он снимается при размонтировании.**
  Цепочка показа последовательна, поэтому копить тайм-ауты в массиве незачем:
  страница оверлея в OBS не перезагружается между сценами и живёт весь стрим.

## Проверка

```bash
pnpm --filter @streamkit/ui test
pnpm --filter @streamkit/ui build
```

Тесты требуют `globals: true` в конфиге Vitest: автоочистка DOM у Testing Library
вешается на глобальный `afterEach`, и без неё соседние тесты видят чужую разметку.

## Известные ограничения

- Шрифты собраны скриптом из Google Fonts и лежат в репозитории (~650 КБ на
  восемь семейств, латиница и кириллица). Все восемь — переменные, поэтому обычный
  и жирный вес берутся из одного файла; скрипта обновления в репозитории нет.
- Кириллица есть у всех восьми семейств, но в кадре они проверены только на
  предпросмотре и в сквозном тесте: живого эфира с каждым шрифтом не было.
