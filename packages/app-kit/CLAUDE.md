# @streamkit/app-kit

## Назначение
Интерфейс, общий для дашборда (`apps/web`) и админки (`apps/admin`): примитивы,
каркас страницы, таблица, диалог подтверждения, график и клиент API с
обновлением токена.

Рендереры виджетов сюда не относятся — они общие с оверлеем и живут в
`@streamkit/ui`, где нет ни Tailwind, ни роутера.

## Состав

| Файл | Что делает |
|---|---|
| `primitives.tsx` | Кнопки, поля, карточка, связь поля с подсказкой и ошибкой |
| `layout.tsx` | Ссылка «к содержимому», мобильное меню, заголовок вкладки, `<main>` с фокусом |
| `data.tsx` | Таблица, «показать ещё», статус, пустое состояние, список «подпись — значение» |
| `dialog.tsx` | Подтверждение действия на нативном `<dialog>`: причина и ввод для необратимого |
| `chart.tsx` | График одной величины и его текстовая сводка — отдельный вход `@streamkit/app-kit/chart` |
| `api-client.ts` | `createApiClient`: запросы, одно обновление токена на вкладку, блокировка между вкладками |
| `theme.css` | Токены цвета (контраст посчитан), курсор, фокус, reduced motion |

## Подключение

```css
@import 'tailwindcss';
@import '@streamkit/app-kit/theme.css';
@source '../../../packages/app-kit/src';
```

`@source` обязателен: Tailwind 4 ищет классы только в файлах приложения, и без
него компоненты пакета приходят без оформления — сборка при этом успешна.

Переводы — из приложения: `common.newTab`, `common.skipToContent`,
`nav.openMenu`, `nav.closeMenu`. У новых компонентов подписи приходят
пропсами, чтобы список ключей не рос.

## Правила

- **React, роутер, i18next, recharts и иконки — peer-зависимости и `external`
  в tsup.** Копия внутри пакета не видела бы ни контекста маршрута, ни
  переводов приложения.
- **Цвет не несёт смысл один.** Статус подписан словом, у графика есть
  текстовая сводка, ошибка — `role="alert"`.
- **Палитру графика выбирает приложение** и проверяет её skill `dataviz`:
  зелёный и красный зарезервированы под статусы.
