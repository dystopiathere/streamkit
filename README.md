# StreamKit

Платформа для стримеров: конструктор виджетов-оповещений, агрегация донат-событий
с внешних площадок и дашборд аналитики.

## Что уже работает

Сквозной путь: регистрация → создание виджета → ссылка для браузер-сорса OBS →
приход события → оповещение на экране → запись в истории. Проверено тестами в
реальном браузере.

- аутентификация с ротацией refresh-токенов, детектом кражи и TOTP;
- шесть типов виджетов — оповещения, цель сбора, таймер марафона, топ
  донатеров, чат Twitch и гости комнаты — с живым предпросмотром тем же
  рендерером, что в эфире;
- сценарии оповещений: донат, фолловер, подписка, подарок подписок, продление,
  биты, рейд и награда за баллы — у каждого свои порог, шаблоны, оформление и
  звук; события Twitch приходят через EventSub сами после подключения канала;
- мультичат Twitch и YouTube одной лентой в кадре и в окне эфира — только
  подключённых по OAuth каналов; YouTube — потоком `streamList` в пределах
  своего бюджета квоты;
- приватные комнаты: гость входит по ссылке без регистрации, его видео и звук
  выводятся в OBS браузер-сорсом; медиа через свой LiveKit, записи нет;
- тариф «Про» через ЮKassa: помесячно или на год с автопродлением, открывает
  приватные комнаты; без ключей магазина комнаты бесплатны;
- публичная главная с ценами, порядком получения услуги и реквизитами продавца —
  то, что ЮKassa проверяет до подключения;
- отзываемые публичные ссылки для OBS (в БД хранится только хэш);
- приём событий через подписанный HMAC-вебхук с защитой от повтора;
- двухслойная дедупликация событий (Redis + уникальный индекс);
- живая лента событий в дашборде;
- подключение DonationAlerts: вход через их OAuth, донаты в реальном времени;
- подключение DonatePay: ключ API из кабинета, донаты опросом раз в двадцать секунд;
- аналитика Twitch и YouTube: зрители, подписчики, часы в эфире с графиками;
- окно эфира: время стрима, зрители по площадкам, чат, последние события и
  виджеты, открытые в OBS, — страницей дашборда или отдельным окном для
  док-панели OBS;
- английская версия дашборда и публичных страниц;
- статистика посещений публичных страниц (Umami, только после согласия);
- раздел приватности: согласия с версиями документов, выгрузка и удаление данных;
- административная панель на отдельном адресе: пользователи и их доступы,
  блокировка, ссылки OBS, комнаты, площадки, платежи, журнал действий и
  статистика платформы; вход сотрудника только со вторым фактором.

## Быстрый старт

Нужны Node 26+, pnpm 12+, Docker.

```bash
pnpm install
cp .env.example .env
```

Сгенерируйте секреты и подставьте их в `.env`:

```bash
node -e "console.log('JWT_SECRET=' + require('crypto').randomBytes(48).toString('base64url'))"
```

```bash
node -e "console.log('ENCRYPTION_KEY=' + require('crypto').randomBytes(32).toString('base64'))"
```

```bash
node -e "console.log('IP_HASH_PEPPER=' + require('crypto').randomBytes(24).toString('base64url'))"
node -e "console.log('TOKEN_HASH_PEPPER=' + require('crypto').randomBytes(24).toString('base64url'))"
```

Поднимите базы и медиасервер комнат и накатите схему:

```bash
docker compose -f infra/docker/compose.dev.yml --env-file .env up -d
```

```bash
pnpm db:migrate
```

Демо-данные и сотрудник админки со вторым фактором (почту, пароль и секрет
TOTP скрипт печатает в терминал):

```bash
pnpm db:seed
```

Запустите приложения:

```bash
pnpm dev
```

- дашборд — http://localhost:5173
- оверлей — http://localhost:5174
- админка — http://localhost:5175 (сотрудник из `pnpm db:seed`)
- API — http://localhost:3000/api
- LiveKit — ws://localhost:7880 (комнаты; поднимается тем же compose)
- фоновый процесс (чат, опрос площадок, донат-коннекторы) — без порта, пишет в
  тот же терминал

## Полный стек в Docker

```bash
docker compose -f infra/docker/compose.yml --env-file .env up --build
```

Дашборд на :8080, оверлей на :8081, админка на :8082, API на :3000, LiveKit на :7880.

LiveKit здесь запускается без `--dev`, и dev-секрет `secret` из `.env.example`
он не примет: `LIVEKIT_API_SECRET` должен быть не короче 32 символов.

## Структура

| Каталог | Что это |
|---|---|
| `apps/api` | NestJS: HTTP, WebSocket и фоновый процесс |
| `apps/web` | Дашборд стримера (React + Vite) |
| `apps/overlay` | Страница для браузер-сорса OBS |
| `apps/admin` | Административная панель (React + Vite) |
| `packages/contracts` | Zod-схемы: общий контракт данных |
| `packages/ui` | Рендерер виджета, общий для дашборда и оверлея |
| `packages/app-kit` | Интерфейс, общий для дашборда и админки |
| `e2e` | Сквозные сценарии Playwright |
| `infra/docker` | Образы, compose, nginx |
| `infra/livekit` | Медиасервер комнат и что сделать перед выкаткой |
| `infra/yandex-cloud` | Прод в Yandex Cloud: Terraform, выкатка, порядок первого запуска |
| `docs/adr` | Архитектурные решения и их причины |
| `docs/legal` | Юридический блок |

Подробности по каждому каталогу — в его `CLAUDE.md`. Общие правила и список уже
пойманных граблей — в корневом [CLAUDE.md](CLAUDE.md).

## Важное о юридической части

Тексты в `apps/web/public/legal/` — действующие редакции: решение опубликовать их
без внешней юридической проверки принял владелец проекта. Какие обещания
документов держит код и что остаётся на операторе (уведомление Роскомнадзора,
подтверждение почтового домена, возвраты): [docs/legal/README.md](docs/legal/README.md).

   подать заявку на повышение квоты (`docs/youtube-quota-request.md`): до неё
   чат YouTube выдержит несколько стримеров в сутки.
4. ~~Приватные комнаты на LiveKit и виджет раскладки участников~~ — сделано.
   Гость по ссылке без регистрации, оверлей — невидимый подписчик комнаты,
   рисующий гостей на машине стримера, а не серверная композиция: та стоила бы
   платформе кодирования видео на каждого стримера (docs/adr/0010). **Перед
   выкаткой** нужны TLS для сигнализации и TURN для гостей за строгим NAT —
   `infra/livekit/README.md`.
5. ~~Собственный приём платежей~~ — сделано в виде подписки на платформу: стример
   платит за тариф «Про» через ЮKassa (docs/adr/0011). **Донатов через платформу
   по-прежнему нет** — это агентская схема с выплатами и 115-ФЗ, ADR 0002 в силе.
   **Перед первым платежом** — автоплатежи для магазина в ЮKassa, подтверждённый
   почтовый домен в Postbox и настоящие цены вместо заглушек (`docs/legal/README.md`).
6. ~~Административная панель~~ — сделано: отдельное приложение за паролем
   прокси, своя сессия сотрудника, роли «поддержка» и «админ»
   (docs/adr/0013). Данных донатеров и гостей панель не показывает.
